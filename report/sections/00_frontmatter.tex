\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Traditional video streaming forces a hard choice: self-hosted servers (like Jellyfin and Plex) keep videos private at home but cannot be easily shared over the internet due to home router firewalls (CGNAT), while commercial platforms (like YouTube and AWS) store all videos in the cloud, leading to high monthly storage and bandwidth bills.

\textbf{CustardFin} solves this problem with a simple rule: \textit{videos stay on the owner's home computer, while the cloud handles only the catalog and stream coordination}. Marking a video ``Public'' uploads only a small JSON manifest ($\le 3\text{ KB}$) containing the title and streaming playlist—never the original video file. This reduces cloud operational costs by \textbf{95.89\%} compared to traditional cloud video hosting.

The system uses pre-encoded 4-second HTTP Live Streaming (HLS) with GPU hardware acceleration (NVIDIA NVENC, with automatic CPU fallback), keeping host CPU usage below 5\%. Home nodes connect to the cloud using an outbound-only reverse tunnel (FRP), completely bypassing residential ISP CGNAT without opening any router ports. To protect home upload speeds, an \textit{Origin Shield} cloud cache pulls each requested video chunk once and serves all other viewers directly from the cloud. A 10-stream cap per node prevents home network overload, while local users on the same Wi-Fi enjoy instant, direct playback with under 4~ms latency. CustardFin is built with Go and Next.js using 100\% free and open-source tools, and has been verified across local containers, local cloud emulators, and Google Cloud Platform (GCP).
