\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Traditional personal media streaming architectures present an intractable trade-off: self-hosted media servers (such as Jellyfin and Plex) trap content on private home local networks behind residential ISP Carrier-Grade Network Address Translation (CGNAT), whereas centralized public video hosting platforms (such as YouTube and AWS S3/CloudFront) impose recurring cloud storage bills, bandwidth egress penalties, and complete loss of video ownership. 

\textbf{CustardFin} solves this challenge by introducing a hybrid edge-cloud video streaming architecture adhering to a strict governing invariant: \textit{video binaries remain permanently on the content owner's home edge machine, while the cloud control tier manages only a lightweight searchable catalog and ephemeral stream coordination}. Marking a video ``Public'' syncs only a $\le 3\text{ KB}$ JSON metadata manifest to a cloud PostgreSQL database without uploading the underlying media binary, achieving approximately \textbf{98\% reduction in cloud operational costs} compared to conventional cloud VOD infrastructure.

The platform implements pre-encoded 4-second HTTP Live Streaming (HLS) with automatic hardware acceleration probing (NVIDIA NVENC with automatic CPU fallback), reducing playback compute to under 3\% CPU utilization. Home edge nodes punch through residential ISP CGNAT via outbound-only Transport Layer Security (TLS) reverse tunnels using Fast Reverse Proxy (FRP), eliminating inbound open router port requirements. To protect constrained residential uplink bandwidth, a cloud-side 24-hour LRU \textit{Origin Shield} object cache serves subsequent viewers after an initial on-demand pull, complemented by dynamic master playlist rewriting (adaptive ladder pruning) and a strict 10-stream remote admission limit. Furthermore, local clients benefit from zero-latency LAN streaming via an embedded, offline-capable Mini-Jellyfin web interface on the home daemon. The entire system is implemented in Go and Next.js utilizing 100\% free and open-source software (FOSS), with multi-topology deployment verified live across local development containers, Floci cloud emulation, and Google Cloud Platform (GCP).
