\chapter{Team Contributions and Division of Work}
\label{chap:contributions}

\vspace{-0.4cm}
CustardFin was collaboratively designed, implemented, and validated by two MCA students: \textbf{Anish Ghadi} (Seat No.: \textbf{25P0320009}, Edge Lead) and \textbf{Anosh Chodankar} (Seat No.: \textbf{25P0320010}, Cloud Lead).

\vspace{0.15cm}
\noindent\textbf{Summary of Individual Deliverables:}
\begin{itemize}
    \setlength{\itemsep}{0pt}
    \setlength{\parskip}{0pt}
    \item \textbf{Anish Ghadi (Edge Tier Lead):} Home Edge subsystem (\texttt{apps/edge}), recursive scanning, SHA-256 hashing, managed FFmpeg (NVENC GPU probe with CPU fallback), embedded SQLite WAL, outbound FRP reverse tunnel daemon, and Mini-Jellyfin offline web UI.
    \item \textbf{Anosh Chodankar (Cloud Tier Lead):} Cloud Control Plane (\texttt{apps/api}) and Web Tier (\texttt{apps/web}), hexagonal Go REST API, PostgreSQL catalog schemas, Redis heartbeat tracking, Origin Shield S3 cache with HMAC-SHA256 signing, and Next.js 15 web player.
\end{itemize}

\vspace{0.15cm}
