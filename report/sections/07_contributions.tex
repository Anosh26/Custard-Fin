\section{Collaborative Engineering Approach}
\label{sec:contrib_model}
% ------------------------------------------------------------------------------

To ensure smooth collaboration across the edge and cloud components, the team used modern software engineering practices:
\begin{itemize}
    \item \textbf{Monorepo Structure:} The project was organized into modular Go packages (\texttt{apps/edge}, \texttt{apps/api}, and \texttt{libs/contracts}) linked via \texttt{go.work}, alongside a Next.js frontend (\texttt{apps/web}). This allowed parallel development without dependency conflicts.
    \item \textbf{Contract-First Design:} Shared data structures and API interfaces were defined first in \texttt{libs/contracts} and documented in \texttt{docs/api/openapi.yaml}. Both members wrote code and tests against these contracts.
    \item \textbf{Conventional Commits and Code Reviews:} All code changes used conventional commit tags (such as \texttt{feat(edge): ...} and \texttt{feat(api): ...}) and passed automated tests before merging.
    \item \textbf{Pair Programming:} Complex integration components—specifically reverse tunnel handling and Origin Shield caching—were developed collaboratively through pair programming.
\end{itemize}

\section[Contribution of Anish Ghadi]{Contribution of Anish Ghadi \\ (Seat No.: 25P0320009)}
\label{sec:contrib_anish}
% ------------------------------------------------------------------------------

Anish Ghadi served as the lead developer for the \textbf{Home Edge Subsystem (\texttt{apps/edge})}, hardware transcoding, and local storage:

\begin{enumerate}
    \item \textbf{Media Scanner and File Hasher (\texttt{internal/adapters/fs}):}
    \begin{itemize}
        \item Built the recursive folder scanner to discover and index video files (\texttt{.mp4}, \texttt{.mkv}, \texttt{.mov}, \texttt{.avi}).
        \item Implemented the hashing algorithm using file headers and metadata to generate unique IDs, avoiding duplicate transcodes when files are moved.
    \end{itemize}

    \item \textbf{FFmpeg Transcoder and Hardware Acceleration:}
    \begin{itemize}
        \item Created the managed FFmpeg subprocess runner (\texttt{internal/adapters/ffmpeg}) using Go's \texttt{exec.CommandContext} with safe cancellation.
        \item Implemented hardware encoder probe prioritizing NVIDIA NVENC with automatic fallback to CPU software encoding (\texttt{libx264}).
        \item Added a 1-second test encode to verify GPU availability before starting batch jobs.
        \item Configured strict 4-second HLS segmenting with aligned keyframes (\texttt{-g 120} at 30~fps) for smooth quality switching.
    \end{itemize}

    \item \textbf{Embedded SQLite Database (\texttt{internal/adapters/sqlite}):}
    \begin{itemize}
        \item Integrated pure-Go SQLite (\texttt{modernc.org/sqlite}), allowing the edge daemon to compile into a single static binary without CGO.
        \item Configured Write-Ahead Logging (WAL) and a 5-second busy timeout to prevent database locks during simultaneous streaming and transcoding.
        \item Created database tables and migrations for media paths, transcode status, and private watch progress (Invariant~8).
    \end{itemize}

    \item \textbf{Outbound Reverse Tunnel Client (\texttt{internal/adapters/frp}):}
    \begin{itemize}
        \item Integrated the Fast Reverse Proxy (\texttt{frpc}) client to establish outbound TLS connections to the cloud relay, bypassing residential CGNAT (Invariant~2).
        \item Added automatic reconnection logic with exponential backoff for network drops.
    \end{itemize}

    \item \textbf{Mini-Jellyfin Offline Web Hub:}
    \begin{itemize}
        \item Built the embedded web UI served directly by \texttt{edged} on port \texttt{8089}.
        \item Provided local HLS video playback and hardware status indicators when disconnected from the internet.
    \end{itemize}

    \item \textbf{Hardware Benchmarking and Lab Testing:}
    \begin{itemize}
        \item Created the GPU benchmarking script (\texttt{scripts/bench-gpu}) and collected performance data comparing NVENC ($322.3\text{ fps}$) against CPU ($33.6\text{ fps}$).
        \item Configured and operated the NVIDIA RTX 4060 edge test machine during laboratory demonstrations.
    \end{itemize}
\end{enumerate}

\section[Contribution of Anosh Chodankar]{Contribution of Anosh Chodankar \\ (Seat No.: 25P0320010)}
\label{sec:contrib_anosh}
% ------------------------------------------------------------------------------

Anosh Chodankar served as the lead developer for the \textbf{Cloud Control Plane (\texttt{apps/api})}, presentation frontend (\texttt{apps/web}), and cloud deployment:

\begin{enumerate}
    \item \textbf{Cloud Control API (\texttt{apps/api}):}
    \begin{itemize}
        \item Built the Go REST API using standard library packages (\texttt{net/http}, \texttt{log/slog}) following hexagonal architecture.
        \item Implemented versioned REST endpoints (for auth, nodes, catalog, and media playback) with strict schema validation.
    \end{itemize}

    \item \textbf{PostgreSQL Database and Manifest Synchronization:}
    \begin{itemize}
        \item Designed relational database schemas for users, edge nodes, and public video catalogs.
        \item Integrated connection pooling (\texttt{pgxpool}) and type-safe query generation using \texttt{sqlc}.
        \item Built the manifest sync worker that ingests $\le 3\text{ KB}$ JSON metadata manifests while leaving video files on home drives (Invariant~1).
    \end{itemize}

    \item \textbf{Redis Heartbeat and Node Health Tracking (\texttt{internal/adapters/redis}):}
    \begin{itemize}
        \item Implemented node health tracking using Redis keys with 20-second TTLs (\texttt{heartbeat:\{node\_id\}}).
        \item Enabled automatic offline detection: when a node disconnects, its key expires and the catalog flags it as \textit{Offline} within seconds.
    \end{itemize}

    \item \textbf{Origin Shield Caching and URL Security (\texttt{internal/adapters/s3}):}
    \begin{itemize}
        \item Designed the \texttt{ChunkCache} interface and built the S3 cache adapter using AWS Go SDK v2 (compatible with AWS S3, MinIO, and Floci).
        \item Implemented single-ingest caching (Invariant~7): cache misses pull video segments once through the tunnel, store them in S3 with a 24-hour LRU purge policy, and serve subsequent viewers from the cache.
        \item Added HMAC-SHA256 signed playback URLs with short expirations to prevent unauthorized video hotlinking (Invariant~9).
    \end{itemize}

    \item \textbf{Next.js 15 Web Frontend (\texttt{apps/web}):}
    \begin{itemize}
        \item Developed the responsive web application using Next.js 15 App Router and React Server Components.
        \item Built the custom video player using \texttt{hls.js}, including quality selection and a ``Stats for Nerds'' telemetry overlay showing buffer health and cache status.
        \item Implemented the ``My Edge Library'' management modal and Developer Diagnostics panel.
    \end{itemize}

    \item \textbf{Cloud Deployment and Laboratory Setup:}
    \begin{itemize}
        \item Deployed the cloud stack on a Google Cloud Platform VM (\texttt{e2-standard-2}) with Caddy reverse proxy and automatic Let's Encrypt TLS.
        \item Configured the Floci local cloud emulator for zero-cost lab demonstrations.
    \end{itemize}
\end{enumerate}

\section{Joint Responsibilities and Shared Work}
\label{sec:contrib_joint}
% ------------------------------------------------------------------------------

Both team members collaborated on core system design and testing milestones:
\begin{itemize}
    \item \textbf{System Constraints:} Defined the 10 Non-Negotiable Invariants governing video storage, networking, licensing, and capacity limits.
    \item \textbf{Admission Control Design:} Formulated the 10-stream remote cap per node (Invariant~10), implementing stream tracking and \texttt{HTTP 429 Retry-After} responses.
    \item \textbf{Load Testing:} Designed and executed the 10-viewer concurrency load simulation to verify single-ingest caching.
    \item \textbf{Documentation:} Co-authored setup guides (\texttt{DEMO\_ALL\_MODES.md}), the project presentation slides, and this academic report.
\end{itemize}
