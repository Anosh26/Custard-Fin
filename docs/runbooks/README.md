# CustardFin Runbooks

This directory contains operations, deployment, and rehearsal runbooks for CustardFin:

- [**`RUNNING_GUIDE.md`**](RUNNING_GUIDE.md): Master running guide covering all 4 execution modes (Pure Local, Containers, Floci Multi-PC Lab, and GCP Live Cloud).
- [**`demo.md`**](demo.md): Step-by-step presentation script, live demonstration steps, and viva Q&A defense.
- [**`deploy.md`**](deploy.md): Google Cloud Platform (GCP) Compute Engine VM deployment guide, firewall rules, ports table, and edge client configuration.
- [**`troubleshooting.md`**](troubleshooting.md): Diagnosis and emergency recovery guide for edge nodes, reverse tunnels, and streaming ports.
