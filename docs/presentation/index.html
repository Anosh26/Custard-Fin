The Core Problem

Why Current Apps Fail: Big Cloud vs Home Servers

Big Cloud (YouTube / AWS S3)
Compounding Cost & Privacy Loss
  • Monthly Storage Bills: Storing terabytes permanently in S3 bills hundreds of dollars monthly.
  • Lost Ownership & Ads: Creators surrender raw videos to corporate platform algorithms and ads.
  • High Bandwidth Fees: Centralized video distribution bills crushing fees for every GB watched.
Home Servers (Plex / Jellyfin)
CGNAT Trapped & Choked Upload
  • Blocked by ISP CGNAT: Residential ISPs block incoming ports; external streaming needs risky port forwarding.
  • No Public Discovery Feed: Videos remain trapped on private islands with no community feed.
  • Choked Home Upload: Just 3 to 4 outside viewers streaming simultaneously saturate home Wi-Fi upload.
The CustardFin Fix: Videos stay at home • Cloud only stores a ~3 KB info file • Cloud cache protects home Wi-Fi.

Protecting Home Wi-Fi

Origin Shield & Router: Protecting Home Wi-Fi

STREAM ROUTER LOGIC
Smart Play Router (4-Step Check)
  • 1. Redis 15s Online Check: If heartbeat expired, serve cached chunks only, else display "Node Offline".
  • 2. Same Wi-Fi LAN Bypass: Home viewers stream directly over LAN — 0 cloud bandwidth used!
  • 3. Cloud Cache Hit: Serves requested 4s chunk from GCP bucket immediately with signed URL.
  • 4. Cache Miss Pull-Through: Pulls chunk once through tunnel; hard cap of 10 remote streams.
10-Stream Limit: Protects home connection with clear "Node Busy" (HTTP 429)
BANDWIDTH SHIELD
Home Wi-Fi Protection (92.4% Saved)
  • Upload Once: Home PC uploads each hot 4s chunk exactly once (5 Mbps).
  • Serve Thousands: GCP Origin Shield cache handles all viral viewers.
  • 92.4% Bandwidth Saved: Home Wi-Fi never saturates during viral spikes.
Verified: 92.4% upload bandwidth saved in live 10-viewer load testing
